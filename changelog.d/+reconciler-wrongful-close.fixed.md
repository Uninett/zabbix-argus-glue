Stop the reconciler from closing Argus incidents whose Zabbix problem is still open. A problem missing from a single (possibly incomplete) Zabbix fetch is now re-confirmed as resolved before its incident is closed, and an empty problem fetch no longer closes incidents at all. Creation attempts that Argus rejects as duplicates — e.g. for an incident an operator has force-closed — are handled and logged informatively (with the existing incident id and close time) instead of raising errors every pass.
